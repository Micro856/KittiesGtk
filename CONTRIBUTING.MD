# Contributing to KittesGtk
By creating a Pull Request you accept the following terms.

## Usage of AI
Code and Translations written by a Large Language Model, Coding Agent, Artificial Inteligence, and whatever else you can call it,
won't be accepted. Every PR suspected as “*vibecoded*” will be closed. AI can be a great tool to assist a person if used correctly,
that means programming/translating instead of the user is not considered assisting. If you ***REALLY*** need to use AI here is a
better way to do it.

### Acceptable usage of AI
- Use ***ALWAYS*** as a last resort - If reading documentation, and doing web searches is not enough you can ask AI for assistance.
- Asking for assistance means presenting the problem to the model, and asking for possible solutions.
- Based on suggested solutions, select the few you think are the best, and consult Library's documentation and/or valadoc.org to get a better understanding of how to implement the function/call available in the Library.
- ***Ignore*** code snippets the model gives you, sadly often unavoidable, at most use it as an idea of possible structure, but never add the code given by AI directly into program's codebase. 

### How to tell if a person is hiding AI usage?
Many people will try to hide the unacceptable AI usage. Here's how I will try to detect them.
1. PR creator made ***A LOT*** of changes to the codebase
2. Written code (functions, etc.) feels too short or over complicated
3. PR creator is not able to clearly explain what the written code does step by step

## Training AI on KittiesGtk
I would personally not want KittiesGtk code to be used to train AI models. The GPLv3 licence does allow for redistributing the code or modifying it, but if a code snippet, taken exactly as it is in KittiesGtk, finds its way into an another project using a diffrent license, this might break the license terms.
