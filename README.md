# Kitties
![Kitties icon](data/icons/hicolor/scalable/apps/io.github.Micro856.Kitties.svg)

Kitties (KittiesGtk to be exact) is an app that lets you display a random image of one of the available cats. 
These pictures come from various APIs including [api.garythe.cat](https://api.garythe.cat) and [rory.cat](https://rory.cat). 

Features:
- Support for Multiple APIs
- Saving Cat Images
- Keyboard Navigation

KittiesGtk is a port of [my macOS app Kitties](https://github.com/Micro856/Kitties) to Vala and Libadwaita.
