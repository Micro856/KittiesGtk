# Kitties

Kitties (KittiesGtk to be exact) is an app that lets you display a random image of one of the available cats. Cat pictures come from various APIs including [api.garythe.cat](https://api.garythe.cat) and [rory.cat](https://rory.cat). 

KittiesGtk is a port of [my macOS app Kitties](https://github.com/Micro856/Kitties) to Vala and Libadwaita.
