![Kitties icon](https://raw.githubusercontent.com/Micro856/KittiesGtk/refs/heads/master/data/icons/hicolor/scalable/apps/io.github.Micro856.KittiesGtk.svg)


Kitties is an app that lets you display a random image of one of the available cats. 
These pictures come from various APIs including [api.garythe.cat](https://api.garythe.cat) and [rory.cat](https://rory.cat). 

Features:
- Support for Multiple APIs
- Saving Cat Images
- Keyboard Navigation
